## Interpretation

`auto` selects native H2 streams when destination scope, capability, capacity, and admission health permit.
It uses packets during cooldown or after a safe refusal before admission.
It does not replay application bytes.
An ambiguous open failure still fails the current flow.

Native streams cover eligible direct proxy traffic to a userspace peer's own IPv4 address.
Kernel TUN forwarding keeps the packet path.
The policy does not predict throughput or loaded latency.
H2 retains shared TCP head-of-line blocking.

The delivery checks use normal transport selection.
They verify fleet integration.
They do not establish native H2 use for every transfer or long-term availability.
This rollout adds no throughput benchmark or artificial-loss experiment.
The earlier repeated jpaws-LA trials remain the performance evidence.

The [QUIC admission analysis](../design/quic-proxy-policy.md) identifies useful policy reuse.
QUIC already has native streams and datagrams.
Local capacity fallback and endpoint cooldown could improve native-open handling.
That conclusion comes from source analysis.
No QUIC performance gain was measured or deployed.
