Control path

Solid UI → Tauri IPC and async Rust adapter → Swift main queue → OS provider message → Extension control queue → C FFI control API → Rust core

One visible poll returns system state and a network snapshot. The Rust command awaits the mobile plugin. The Swift manager and provider retain their ownership queues. Provider admission remains closed after a timeout until the callback returns or the VPN disconnects. Connection generations reject old snapshots and logs.

Packet path

iOS packet flow → Swift batch adapter → C FFI → Bounded core ring → NIC forwarding → Authenticated transport
Authenticated transport → NIC writer → Bounded core ring → Borrowed C callback → Swift Data copy → iOS packet flow

Packets do not enter JavaScript. The adapter keeps 64-packet batches and 128-packet rings. The shutdown barrier protects borrowed callback data. Device throughput, memory use, and signed operation remain unmeasured.
